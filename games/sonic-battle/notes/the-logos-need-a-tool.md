# prove only compares a game's sound when a file named CANARY sits in the game's folder.

About: logos

Proof: #999

Found while measuring the jump: with no such file, `prove` skips the sound bands and reports a match that isn't real. An empty file is enough. The team adds one for every game as its first step on the sound, and the person being helped doesn't need to hear about it, as it's only bookkeeping.
